# public-data｜読者が使える一次データ（CSV）

金利・還元率・マクロ等の一次データを、読者がそのまま使える形（CSV）で公開しています。
**単価（offer）などの守秘データは含めません**（公開するのは公的・公表の事実データのみ）。

## 使い方
- **ダウンロード**：下のリンクを開いて保存。
- **Googleスプレッドシートに自動取り込み**：セルに `=IMPORTDATA("<CSVのURL>")` と入力。
